# Image sources

Article, category and book images are stored locally in `frontend/public/images/` so
the site does not depend on third-party image hosts. The author, license and source page
of every image are listed in:

- `frontend/public/images/LICENSES.md`
- `seo-images.json` (the metadata source of truth; see `SEO_IMAGES.md`)
- the public Sources & Image Credits page at `/sources`

Each news story's own source articles are cited in that article's reference list.
